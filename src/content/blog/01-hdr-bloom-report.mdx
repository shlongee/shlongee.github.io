Bright objects look flat unless soft light spills around them.<br/>
Here is how I built a fast HDR bloom pass in [Raylib](/tags/raylib/)<br/>
and fixed 8-bit banding.

## 1. The 5-Mip Bloom Chain (13-Tap Blur)
Instead of running one slow giant blur,<br/>
shrink the bright pixels five times and blend them
back up:

* **Prefilter** pixels above a soft-knee threshold.
* **Downsample** 5× with Jimenez’s 13-tap filter.
* **Upsample** and blend each mip onto the frame.

```glsl
// Soft knee (smooth transition) Prefilter 
vec3 softThreshold(vec3 color, float threshold, float knee) {
  float br = max(color.r, max(color.g, color.b));
  float soft = clamp(br - threshold + knee, 0.0, 2.0 * knee);
  soft = (soft * soft) / (4.0 * knee + 1e-5);
  float contrib = max(soft, br - threshold) / max(br, 1e-5);
  return color * contrib;
}
```

## 2. Bugs: BeginDrawing() & #version 330
1. **Double `BeginDrawing()`:** <br/>
Calling `EndDrawing()` inside `ApplyBloom()` and `main()`<br/>
halved FPS and flickered UI text.
2. **Missing `#version 330`:**<br/>
Omitting that header in the [GLSL](/tags/glsl/) fragment shader<br/>
broke `compositeFS` uniform updates.

## 3. Why Float16 Fixes 8-Bit Color Banding
An 8-bit channel `(R8G8B8A8)`<br/>
stores 256 fixed steps `(1/255)`.<br/>
Faint glow tails snap into stairs,<br/>
and strong bloom turns them into rings.

Float16 `(R16G16B16A16)` packs tiny exponents near zero,<br/>
keeping faint [HDR](/tags/hdr/)
light silky smooth:

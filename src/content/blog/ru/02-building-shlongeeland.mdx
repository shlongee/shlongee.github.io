Этот сайт объединяет статические страницы [Astro](/ru/tags/astro/) с шейдерами [Three.js](/ru/tags/threejs/) и [WebGL](/ru/tags/webgl/).
Вот как устроена его магия внутри:

## 1. Живой холст через Astro ClientRouter
При переходе с **Главной** в **Блог** полярное сияние не сбрасывается.
`ClientRouter` в Astro подменяет содержимое страницы, пока
`transition:persist` не даёт WebGL-элементу `<canvas>` остановиться.

## 2. Лечим полярный шов atan() в GLSL
Сырой `atan(y, x)` делает резкий скачок там, где `−π` переходит в `+π`.
Передача замкнутых координат окружности `(cosθ, sinθ, depth)`
в 3D-шум с лёгкой спиральной пульсацией полностью убирает шов:

<SeamVisualizer lang="ru" />

## 3. Инстансинг частиц заголовка на Three.js
Чтобы нарисовать **SHLONGEELAND** живыми частицами,
мы рендерим текст в 2D-canvas,
создаём квады через `InstancedBufferGeometry`
и раскрашиваем каждую точку формулой **ядро + ореол**:

```glsl
float core = exp(-d * d * 6.5);
float halo = exp(-d * 2.4) * 0.58;
```

<ParticleBloomVisualizer lang="ru" />

## 4. 3D-грибы и статический поиск на Preact
* **3D-грибы:** Выточены через `LatheGeometry` с подсветкой краёв по Френелю и откликаются на клик через `Raycaster`.
* **Мгновенный поиск:** Сгенерированный при сборке <br/>`/search-index.json` фильтрует записи
по тегам и словам прямо в **Preact** без всякого бэкенда.
